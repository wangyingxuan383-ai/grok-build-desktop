## 实现

| 范围 | 内容 |
|---|---|
| 登录/版本门禁 | 登录、添加账号不经过 CLI 版本门禁；登录后连通性检查只作提示，不回滚已成功的登录；会话启动遇到未验证的 CLI 版本只写日志，ACP 握手失败才阻断并给具体原因（CLI 升级流程的兼容名单保持不变） |
| 外壳 | 侧栏（编程/图像分段开关、项目树含会话、底栏）、框架化主区与右窗格、新标题栏；token、lucide 图标、Button/Badge/Segmented 等基础组件；清理 88 条无引用旧样式；设置/账号/任务等整页面板去掉面包屑与二层卡片；主按钮统一为单色 |
| 子智能体 | 对话内单卡片（委派内容、状态、指标、可展开结果）；“查看会话”在右窗格打开只读子会话，复用回合组件，运行中每 2.5 秒刷新并可停止；读取 CLI 的 `subagents/<id>/meta.json` 与 `output.json`；看板事件不再抹掉已知模型/Agent 字段 |
| 图像模式 | 与编程模式共用外壳；每个图像会话对应一个真实 CLI 会话（`--session-id` 首次、`--resume` 之后，会话丢失自动新建）；对话流会话页与新输入框；独立图库（瀑布流、筛选、多选删除，失败记录可清理）；单条记录/会话可删（可选同时删除原图，仅限会话自身目录）；会话可重命名，标题不被覆盖；空会话不持久化 |
| 图像产物 | 只接受工具真实返回的产物，参考图不再当结果 |
| 探针 | probe-v070-ui、image-failure、remaining、library、pages 已按新 DOM 更新并对开发构建与打包产物通过 |
