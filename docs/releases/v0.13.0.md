# Desktop 0.13.0 / Grok Remote 0.4.3 本地检验版

本版补足已有工作流，沿用现有界面风格。桌宠暂不包含在本版中。

## 随手使用

- 托盘可直接打开快速提问、截图提问、收件箱及正在运行或等待处理的会话。
- 快速提问支持已有会话和使用项目默认配置新建会话。失败重试复用已创建的会话，内容保留供检查。
- 截图使用系统截图工具，完成后明确点击“引用剪贴板”；附件可在发送前检查和移除。
- 全局快捷键默认留空；应用内快捷键可在常规设置中调整、检查冲突和恢复默认。
- 关闭窗口首次询问，也可在设置中选择托盘或退出。任务栏状态和按需防休眠复用应用内真实活动。

## 草稿与反馈

- 输入框旁的片段入口可管理常用提示词，填写 `{{变量}}` 后插入当前草稿。手机可切换“这部手机 / 当前电脑”，私人手机片段不会自动上传。
- 图像页拖入图片会进入图像参考，不再误入编程草稿。
- 网页预览支持明确选取元素并附截图反馈。Diff 可对所选行添加批注，核对所属会话和变更版本后加入草稿。
- 导出会话支持 Markdown 和静态 HTML。默认脱敏，可先预览；导出不会启动或恢复 CLI 会话。

## 提醒与设置

- 通知包含会话名称，收件箱按待处理、失败和完成未读排序；配置调整不产生完成提醒。
- 可从托盘或设置暂停系统提醒一小时，收件箱继续记录。额度提醒默认关闭，仅根据已有查询明确返回的数据记录到收件箱。
- 外部 CLI 配置变化后更新目录展示，解析失败保留最近有效数据，不重启活动会话。
- 旧 CLI 不支持回合内插话时，消息保留为下一回合队列，当前任务继续运行。

## 验证边界

本地自动化与实际组件渲染不等同于真机验收。Android 输入法、手势、锁屏后的后台恢复、系统覆盖安装，以及真实账号模型结果仍需在具体设备和账号上检验。Windows 通知到达受系统通知设置影响。此文档描述本地候选，不表示已经公开发布。
