# Grok Build Desktop v0.9.6｜任务可靠性与 Desktop 工具入口

## 更新内容

- 修复定时任务完成时覆盖运行期间的编辑、暂停状态，以及删除后被旧运行恢复的问题。
- 统一任务执行配置，保留独立任务的历史会话；编辑名称和提示词不会改变间隔调度节奏。
- 日历任务使用持续重复触发和时区校验，避免依赖前一次 Worker 登记后续时间。
- 新增 Desktop MCP 与持久任务 Skill，支持通过对话管理任务、继续当前会话，或选择独立任务的新上下文。
- 绑定任务仍可修改工作区；下次执行在会话空闲后迁移同一会话，保留历史。等待当前会话不占全局执行槽。
- Computer Use 增加服务端开关、持久确认、跨进程桌面互斥与主会话身份校验，支持自然语言选择工具。
- 完善原生子智能体 ID、取消入口和 Agent 配置字段保留；能力状态按实际会话证据展示。

## 验证与兼容边界

实现阶段曾完成全量 971 项通过、9 项实机测试跳过。审查修正后完成 58 项定向回归、类型检查、生产构建、任务中心 DOM 检查与 Windows 未注册任务 XML 解析；没有将此前全量结果冒充修正后的全量结果。

**本机 CLI 1.0.30 的完整合同及真实模型调用尚未验收。** Desktop MCP 和 Computer 工具要求 CLI 提供 PreToolUse 身份和 updatedInput；不支持时会拒绝执行。新对话式能力尚不能认定已达到端到端可用标准。

真实 Windows 到时触发、跨夏令时运行、迁移后 CLI 会话恢复和真实 GUI 操作仍待验收。XML 解析不等于实际触发通过。本版不会自动升级 Grok CLI，不包含分段下载器或云端多机调度。
