# Grok Build Desktop v0.9.3｜插话、持久队列与子 Agent 可靠性

## 简洁版

- 重做忙碌会话的后续消息：未提交消息由 Desktop 本地持久队列管理，编辑、排序、叉号撤回和“撤回全部”不再调用 CLI 中不存在的方法。
- 当前回合插话改用 CLI 真实 `_x.ai/interject` 接口，并补齐回合结束、Plan、权限、问题等待、超时和不支持接口时的安全回退。
- 修复子 Agent 进度不显示、刷新后身份漂移和中间进度被误判为完成。
- 修复 Session Info / Session Usage 的 ACP 私有扩展传输名；会话信息、用量、Plugins、MCP 和 Commands 已在 CLI 1.0.3 上完成无推理能力验证。
- 加固会话恢复、草稿认领、附件账本、Provider 路由诊断、媒体缩略图和 Host 异常退出后的重复发送保护。

## 详细版

### 后续消息、队列与插话

- 经真实能力探针确认，CLI 1.0.3 没有 `queue/edit`、`queue/remove`、`queue/reorder` 和队列专用 `interject` mutation。此前 0.9.2 基于这些假接口的实现已完全替换。
- Enter 在忙碌时加入所属会话的 Desktop 持久 follow-up 队列；消息在真正交给 `session/prompt` 前保持可编辑、可排序、可撤回。
- 队列每次只在会话空闲且没有 Plan、权限或问题门时提交一条。重启后只续送从未提交的 `queued` 意图，不重放 `sending/accepted` 项。
- Ctrl+Enter 当前回合插话使用真实 `_x.ai/interject`。CLI 不支持、确认超时或回合刚好结束时，消息会保留为可撤回的下一回合，而不是丢失、锁死或重复执行。
- 编辑、撤回、批量清空和插话结果会同步附件账本；未提交图片不会在重开会话时复活成已发送用户气泡。

### 子 Agent 与会话运行时

- 支持只带 `child_session_id` 或只有 progress 的子 Agent 生命周期事件；spawn、progress、finished 按稳定 child Session 合并为同一记录。
- Dashboard 只依据明确终态结算；普通进度中的耗时不再触发假完成，`cancelled` 正确显示为已停止。
- 修复 CLI 权威 `turn_completed` 与 Prompt RPC 重复结算造成的重复状态、重复指标或重复队列终态。
- 同一会话的重叠打开会共享单一 ACP owner；草稿首次发送、迟到 hydration 和 Host 异常退出均增加所有权保护。

### CLI 扩展与数据真实性

- ACP 逻辑扩展名继续使用 `x.ai/...`，传输边界统一转换为 `_x.ai/...`。Session Info、Session Usage、Plugins、MCP 和 Commands 已在本机 CLI 1.0.3 上无提示词验证。
- Session Info 不再把累计 `totalTokens` 当作当前 Context 占用；费用仍只展示 CLI 或 Provider 返回的明确字段。
- CLI 1.0.4–1.0.5 保持离线源码/Wire Fixture 前向兼容证据，未经用户执行固定目标升级和 live 验证，不冒充已实机验证。

### Provider、媒体与诊断

- Provider 会话记录不含凭据的 Route Receipt，区分路由、认证、协议翻译、上游和下游错误阶段。
- 可读的空 Provider 索引视为用户真实状态，不会被旧备份重新恢复已删除配置。
- 会话媒体列表使用有界缩略图；缩略图失败时回退可用原图，不会直接误报“图片文件不可用”。
- MCP 结构化结果保持字符串和 64 位 ID 精度，并在主进程执行深度、条目和字节限制。
- 诊断信息可说明 `GROK_CONFIG` / `GROK_CONFIG_PATH` 来源类别，但不会记录凭据或完整私人路径。

## 验证与升级说明

- 完整离线门禁：119 个测试文件中 113 个通过、6 个 opt-in live 文件跳过；844 项通过、9 项 live 跳过。
- TypeScript、生产构建、Renderer 分块、Native Host、Electron Fuses、当前版本 UI、Task Scheduler、Portable 中文/空格路径和公开安全扫描通过。
- 安装程序与 Portable 均为未签名 Windows x64 资产；请下载同一 Release 中的 `SHA256SUMS.txt` 校验。
- 本版本不会静默升级 Grok CLI。当前 live 验证仍为 CLI 1.0.3；1.0.4–1.0.5 只有离线兼容证据。
- 真实 Provider、媒体、Plan 写入和 Computer Use 能力仍取决于用户账号、本机环境及上游服务。
