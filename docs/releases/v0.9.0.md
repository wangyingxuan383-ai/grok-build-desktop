# Grok Build Desktop v0.9.0｜CLI 1.0.3 与新版额度

## 简洁版

- 完整适配 Grok Build CLI 1.0.3，并保留固定目标验证、失败回滚和禁止 CLI 自更新。
- 修复新版额度：按官方 `billing?format=credits` 显示实际周/月周期；正确处理 proto3 零值省略，不再伪造月额度、`$0/$0` PAYG 或 `$0` 预付余额。
- 修正 1.0.1+ 回退语义、动态模型刷新、媒体工具识别、后台任务清理和窗口恢复。
- 新增 `grok du` 诊断和显式 Memory trace 导出。

## 详细版

### CLI 与会话

- 兼容档案覆盖 1.0.0–1.0.3，并保存逐版本脱敏 Wire Fixture；未知未来版本不会未经验证直接启用。
- 所有 Desktop 管理的 CLI 进程都使用 `--no-auto-update`。检查可以自动进行，安装仍必须点击“更新并验证”。
- 会话关闭、删除、应用退出、空闲回收和并发上限淘汰前先停止所属后台任务和子 Agent；回收清理失败时保留会话，避免后台工作被直接杀掉。
- Rewind 只回退对话；文件恢复在 Review 中独立预览和确认。

### 额度与模型

- 新任务在首次发送前即可读取官方 ACP 模型目录和模型声明的思考档位，刷新目录不会创建空会话；自定义 Provider 模型继续显示提供商名称并保留路由身份。
- 草稿删除会同步取消待执行自动保存，输入过正文或带附件时也不会被自动保存重新创建。
- 官方 credits 只返回一个当前订阅周期；周周期账号会看到明确说明，而不是一张伪造或空白的月额度卡。

- 使用官方 credits/currentPeriod 结构；周/月由服务端决定。
- PAYG、预付余额、滚动 24 小时限制、订阅档位与自动充值分开显示；有效周期省略百分比时按官方客户端解释为 `0%`，不适用的零值卡片直接隐藏。
- 官方模型从 CLI 目录动态加载；后续新模型会自动进入列表。当前模型暂时消失时不会静默切回 Grok 4.5。

### 媒体、诊断与体验

- 识别 CLI 1.0.3 的 `bundled:imagine` 和真实图片/视频工具，不再依赖旧 `/imagine` 名称。
- 视频参数支持 1–15 秒、4:3/3:4，并保留实际服务端错误详情。
- 新增磁盘占用诊断和手动 trace 导出；Trace 不进入普通脱敏支持包。
- 恢复窗口尺寸/位置/最大化状态，限制异常长会话标题。

## 升级说明

- 应用不会静默更新；请从本 Release 下载 Setup 或 Portable 并核对 SHA-256。
- CLI 更新由设置中的“更新并验证”执行。0.9.0 已验证 stable 1.0.3。
- 真实媒体、Provider 和额度仍以账号及上游服务返回为准。
