## 核心更新亮点

- **一体化顶栏与多窗格自由舞台 V2**：新增无边框一体化标题栏 `ShellTitleBar`、跨项目注意力架 `WorkingShelf`、顶栏活跃回合胶囊 `TurnCapsule`（1Hz 零空转静默诊断与安全权限快捷审批）、`1..8` 命名场景组、多网格分屏预设、单窗格缩放与 2–4 路模型/配置档 A/B 并排对比评测。
- **受控项目脚本、零污染隐藏检查点与会话生命周期 V2**：支持项目生命周期脚本（仓库信任 + 命令摘要双重授权，`runOnSettle` 硬性锁定仅限隔离 Worktree 执行）、每回合自动写入 `refs/grok-build/checkpoints/*` 零污染 Git 检查点、会话 `Snooze` 定时唤醒、运行中预约结算、PR 合并自动结算、脏工作树热迁移 Worktree、分叉子会话结论回并（`Merge Back`）及同会话原地 `/clear`。
- **主题引擎 V2、Composer V2 与审查导览升级**：内置 10 套深浅主题预设、双色种子 WCAG 推导、单层亚克力极光透光、壁纸取色、64 KiB 沙盒自定义 CSS 与 `Ctrl+Alt+A` 紧急外观重置；输入框新增排队消息一键转向（Promote-to-Steer）、本地凭据实时拦截脱敏（`SecretGuardBar`）、大文本粘贴转草稿附件、`@terminal` 引用终端输出；审查面板支持 Unified/Split 切换、架构顺序文件导览、回合检查点对比、PR 模板/PR 栈与 GitHub Issues 关联，以及零外网沙箱行内 HTML 画布与多设备视口预设。
- **双桌面伴侣 15 动作进化与 Grok CLI `1.0.92+` 深度适配**：A/B 双形象扩充 `walk`、`poke`、`stretch`、`perch` 等至各 15 动作槽位，支持像素级 Alpha 穿透、抛投物理与 2×2 图集导入；全面贯通 CLI `1.0.92` 文件夹信任、子智能体权限来源标识、参数化回退（`conversation_only / files_only / all`）、`hunk-tracker`、主题 `.md` 记忆与 `x.ai/session/search` 全文检索。
- **安全加固与伴侣端同步升级**：增加工作区符号链接逐级拦截、远程配对滑动窗口限流与移动端 `Grok Remote 0.5.0`（SSE 恢复、分页去重、会话切换草稿隔离与详情竞态修复）。

> **Android 升级提示**：自 `Grok Remote v0.5.0`（versionCode 17）起启用新的私有签名证书（SHA-256: `7a18ebbaae01423d83824a37580a9d6ba02e791b380016de7f2fe8b86af1215b`）。已安装 `0.4.4` 或更早版本的手机首次升级至 `0.5.0` 时请先卸载旧版再安装新 APK；后续版本将继续支持应用内无缝覆盖升级。
