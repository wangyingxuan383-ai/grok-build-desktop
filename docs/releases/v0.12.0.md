# Grok Build Desktop 0.12.0 / Grok Remote 0.4.0

本次主要升级手机交互、设置与可靠性，同时提供配套 Windows 安装版、便携版和原签名 Android APK。

## 手机升级

- 设置按“这台电脑 / 这部手机”分层，增加搜索、连接与通知健康检查、阅读预览、免打扰和可选应用锁。应用锁开启时系统通知隐藏详情，后台预览受保护；防截屏可独立开启。
- 会话滑动、相册缩放与翻页改用原生手势和动画，统一图标、触感与撤销提示。键盘提供动画跟随和兼容模式。
- 图库按视窗加载，支持 3 / 4 / 5 列、排序、多选收藏/保存和对照。保留网格与卡片，窄屏切换按钮完整显示。
- 统一图片缓存与原子下载，失败可显式重试；传输中心显示真实进度，支持取消/重试，存储页提供分类清理和 Wi-Fi 原图预取控制。
- 定时任务改为四步表单与系统日期/时间选择器，保留原项目绑定和未保存编辑。
- 增加内联待回应卡片、审批历史、发送/排队/停止、未读同步、书签、提示词片段、执行配方和 App 长按快捷入口。
- 完成提醒使用稳定事件 ID，前台、后台与云推送去重；修复迟到偏好、更新状态覆盖、缓存初始化与 APK 丢失后的恢复。

## 电脑配套修复

- 支持显式手机已读确认与新通知协议，兼容旧手机客户端。
- HTTPS 请求代理增加协议示例，额度查询的代理错误提供配置位置与排查说明；官方用量入口更紧凑。
- 更新数学渲染与 TOML 解析依赖，保留现有公开安全、分块预算和发布来源验证。

## 安装与验证

电脑安装版和 Android APK 可覆盖安装保留数据；便携版替换解压目录升级。建议两端一起更新。已安装 0.3.6 的手机可从“设备 → 手机更新”下载并校验，再由 Android 系统确认安装；无需电脑在线。

电脑引导与连接页提供 APK 下载及二维码。本 Release 同时包含两端安装包、统一 SHA-256 清单、Windows 依赖清单/许可证和 Android 签名、版本及源码记录。

类型、单元与界面回归、原生构建、模拟浅深色和窄屏走查通过。600 / 2000 张图片的演示视窗均仅加载附近 30 格。模拟检查不代表真机帧率；输入法、触摸手势、生物识别、后台/FCM 和系统安装确认需在实际手机检验。

APK 使用 arm64-v8a / x86_64 架构。应用锁默认关闭；不会自动更换 CLI 或启用模型执行。
