# 0.14.1 本地检验候选版

- 桌宠拖动后松手停留，保留当前位置并恢复真实任务姿态；重启及隐藏恢复继续使用已有位置记录。
- 右键及托盘“桌面伴侣”增加“落到底部”。锁定、隐藏、拖动、正在下落或已经到底时不可用；减少动态效果、仅状态和勿扰时直接定位。
- 拖动、隐藏、关闭、换形象或改大小会取消旧下落，旧回调不能再把桌宠拉回底部。
- “自定义形象与生图工坊 · 未完善功能”在折叠时即可看到。仍支持透明图片和数据型动画包导入；工坊只准备图像草稿，不提供一键生成完整桌宠。
- 桌宠、托盘和快捷键设置统一为一个“提问”入口；截图、剪贴板和附件保留在提问窗口中。旧版只配置截图快捷键时，将该按键用于统一提问入口；两种都已配置时保留原提问快捷键。

位置仍按整个透明窗口约束在显示器工作区内，顶部预留浮条与状态卡空间。此版本解决松手强制落底，不改变窗口大小或位置记录格式。

交付 Windows 安装版及便携版；不更换已安装应用，不修改手机端，不公开上传。自动化位置及窗口验证不能代替实体鼠标穿透、置顶焦点、125%／150%／200% 混合 DPI、屏幕切换及拔插实测。
