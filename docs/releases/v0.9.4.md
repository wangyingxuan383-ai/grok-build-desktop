# Grok Build Desktop v0.9.4｜CLI 分级升级与会话可靠性

本次汇总 **v0.9.3 之后的累计更新**，不是只包含最后一次修复。

## 简洁版

- CLI 更新提供三种单次策略：**标准升级、尝试新版、强制保留新版**。默认仍受控；高级策略也必须核验固定目标和实际 ACP 能力。
- 修复“转为附件”后文件丢失、发送失败无法恢复、旧草稿覆盖新输入，以及跨会话迟到提示干扰。
- Plan 实施时可选择 Agent 或自动批准，修复执行策略恢复错误；保留继续规划时的自由文字输入。
- 梳理侧栏、Composer、请求卡和更新中心，修复菜单焦点、长文本越界及错误提示复制反馈。
- 补齐 CLI **1.0.6–1.0.13** 离线兼容档案，支持 MCP 表单/浏览器授权请求，并强化表单约束和探针清理。
- 本次完整离线测试 **918 项通过**；**9 项实机测试未运行**。不静默升级 CLI，不把离线结果冒充新版 CLI 实机验收。

## 详细版

### 一、CLI 更新：更灵活，但保留恢复手段

| 本次策略 | 版本名单未覆盖 | 实际核心验证失败 |
|---|---|---|
| 标准升级（默认） | 遵循现有支持范围及同发行线验证规则 | 自动回滚 |
| 尝试新版 | 可明确确认尝试，包括跨主版本 | 自动回滚 |
| 强制保留新版 | 可明确确认尝试 | 正确安装目标版本后保留，暂停实时会话 |

- 升级目标仍来自官方 stable，不接受任意下载地址；公开更新日志领先 stable 时不强制安装尚未下发版本。
- 每次预览确认绑定当前版本、目标、策略和操作，并设过期时间；不同策略的并发请求不会合并为同一个授权。
- 所有策略均验证可执行版本、ACP 协议协商、创建、恢复、关闭和官方删除；强制保留不是跳过验证。
- 下载失败、版本不符或无法启动/识别目标，不属于强制保留兼容失败的范围，仍尝试恢复精确旧版。
- 未验证保留后不自动恢复 ACP、不重发消息，本地正文与草稿保留；更新中心提供重新验证和回滚入口，普通诊断及认证探针不能绕过暂停状态。
- 回滚绑定更新前版本，不要求旧版仍是 stable 最新；stable 检查不可用也不阻塞回滚预览。实际下载旧版仍依赖官方服务，不承诺离线回滚。
- 通过凭据绑定二进制路径、版本和 SHA-256；验证期间或之后被外部替换时，不沿用未知版本授权。
- 日志失败不覆盖更新主因、不跳过回滚或会话恢复；后台任务清理失败仍释放 ACP，部分恢复后重试不重复启动。
- 更新中心分开展示检查、下载、验证、回滚和恢复阶段，以及当前版本、stable 版本、检查时间和安全代理路径类别。

### 二、草稿、附件和会话隔离

- 长文本附件由主进程先物化到会话缓存，迁移到真实会话后使用新路径，重启后按所属草稿目录重新授权。
- 提交快照及引用保存在现有 UI 存储，保护范围覆盖复制、提交、失败和启动恢复；自动保存不能提前清理正在提交的附件。
- 旧提交失败时保留新输入，旧快照作为可恢复记录；重试成功后消费对应失败记录，不再复活旧草稿。
- 清理引用读取与删除共用事务锁，空目录清理不递归删除同期新增附件。
- 修复 Windows 短路径或目录别名造成的文本附件归属误判，继续阻止跨会话目录链接读取。
- 新任务恢复统一由既有草稿 Hook 管理，校验导航目标与编辑世代；快速切换或迟到回包不覆盖当前 Composer。
- 队列、插话、旁路提问和 Stop 提示保持所属会话，不清空其他会话的新草稿或提示；保留 v0.9.3 的本地持久队列与真实插话接口边界。

### 三、高频界面和 Plan

- 侧栏会话行采用单一主入口与权威状态，置顶、归档、导出、重命名和删除收进更多菜单。
- 菜单由显式状态控制，修复旧菜单关闭事件干扰新菜单；补齐方向键、Esc、Tab 和焦点恢复。
- Composer 运行时以排队为主动作，插话/旁路提问归次级菜单，Stop 保持独立；Enter 排队、Ctrl+Enter 插话的既有行为不变。
- Plan 可选择实施后的 Agent/自动批准策略，进入 Plan 前为 Auto 时保留对应默认；修复迟到模式事件把策略降回 Agent 的竞态。
- 统一 Plan、权限、问题和 MCP 请求卡层级，保留自由文字和提交反馈；长账号串、链接、代码与表格使用各自换行/滚动边界。
- 应用错误 Toast 有界、可复制；复制失败可重试，错误正文变化后不会残留“已复制”。
- 渐进抽出 App Shell、Dialog Host、会话行、提交控制及 MCP 卡片，继续复用现有状态与虚拟列表，不重做主题或削弱 Renderer 沙箱。

### 四、CLI 适配、MCP 与维护

- 新增 1.0.6–1.0.13 的脱敏 initialize/事件 Fixture，以及稳定 Desktop 客户端身份和已审计版本的图片感知读取边界。
- 接入 MCP 表单与浏览器授权请求；Stop/退出取消未决输入，临时授权内容不作为普通会话日志持久化。
- 表单在主进程保留并校验数值范围、Unicode 长度和枚举；不支持的 pattern、format、组合及无效约束明确拒绝，不静默丢弃限制。
- 修复 IPv6 回环授权 URL；主、可选 Computer、认证和 live 探针补齐官方会话删除，区分真正删除与退出码为 0 但未找到。
- 上游兼容快照和跟踪脚本同步；更新相关依赖覆盖，保留 ACP、文件、Provider 和凭据位于主进程的边界。

## 下载与验证范围

- **Setup**：Windows x64 安装包；**Portable**：Windows x64 便携 ZIP。附 `SHA256SUMS.txt`、CycloneDX SBOM 和第三方许可证报告。
- 构建工作流生成资产及构建证明，再从草稿 Release 下载回验哈希和证明，成功后发布为 Latest。安装文件仍为未签名资产；构建证明不等同于 Windows 代码签名。
- 源码离线门禁：120 个测试文件通过、6 个 opt-in live 文件跳过；918 项通过、9 项 live 跳过。TypeScript、生产构建、分块预算、公开扫描和依赖审计通过。
- 另有真实 Electron DOM/CDP 回归，覆盖菜单、Toast、MCP 提交、更新阶段和草稿迟到回包；隔离界面探针覆盖三档尺寸及 125%–200% 缩放。
- **已记录的官方 CLI 实机版本仍为 1.0.3**。1.0.4–1.0.13 的源码/离线适配，不代表已在本机完成这些版本的升级、真实 Provider、媒体或完整安装版验收。
- 本次发布不会主动升级用户 CLI，不包含私人会话、账号、代理配置或测试清理清单。
