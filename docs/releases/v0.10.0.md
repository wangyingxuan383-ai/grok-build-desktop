# Grok Build Desktop v0.10.0｜图像工作台与交互可靠性

## 更新内容

- 更新 Electron 43 系列及四个依赖安全补丁，官方 npm 锁文件审计为 0 漏洞。
- 修复 Windows 短路径的原图/编辑器兼容性及草稿启动恢复时的项目身份竞态。

- 统一编程／图像模式切换、项目树、共享菜单与命令搜索；设置和账号页面重新整理，隐藏项目、归档、标签关闭和历史恢复的行为更清楚。
- 新增独立图像会话和图库、参考图、代码会话图片引用、单张及批量删除；图片默认保存到系统图片目录下的 Grok Images。编程会话仍可直接选择生图，项目副本默认写入 generated/images。
- 图像会话复用原生 CLI 会话，支持连续提交修改；Provider 路由明确为独立请求。恢复原生上下文失败时说明本轮开始新上下文，避免伪装连续。
- 修复图像模式无法退出、重复提交、迟到响应覆盖、参考图或旧路径被误识别为结果，以及删除失败后记录丢失的问题；单张删除保留同批其他图片，部分成功产物也可在图库管理。
- 登录、添加 API Key 和切换账号与 CLI 版本白名单解耦；成功保存的账号不会因为后续连通性检查失败被回滚，实际会话连接仍通过 ACP 握手判断。
- 子智能体直接显示在对话中，可打开右侧只读子会话；关联原生 ID 与子会话 ID，刷新保留阅读内容，父回合结束不误报后台子任务完成。
- 文件、图片和生成产物优先在右侧预览；改善文件编辑与阅读位置恢复。提供手动终端和隔离浏览器，含下载反馈与按站点清理。
- 修复 Computer Use 自由文本误分类，区分观察、控制、实际操作与失败；历史回放不作为当前 CLI 的执行证据。
- Token 汇总使用系统时区及一致的筛选口径，生产存储迁到 Worker 内 SQLite；保留 400 天明细、来源和去重，统计文件不保存提示词正文。
- 补齐定时任务迟到确认、会话映射和执行槽可靠性，以及 CLI Hook 加载与会话 MCP 工具清单的适配。

## 验证与已知边界

本机当前构建通过 105 项受影响回归、类型检查、生产构建、Fuses 和打包内容校验；隔离打包版验证了图像账号／设置入口、部分成功图库、单张删除、删除失败保留记录及草稿拒绝后的模式退出。此前各阶段的定向／界面验证继续保留，远程发布以本提交的 CI 结果为准。

用户已实测基础图片生成成功。**真实模型下连续编辑的上下文效果、原生子智能体完整事件／取消语义、Computer 身份证明与 GUI 操作、Windows 到时调度仍有待专项验收。** 只读子会话可能只有委派提示词与最终结果，不承诺完整工具转录。内置终端与浏览器是手动界面，并未因此自动增加 LLM 控制工具。

Renderer 当前总量预算为 19.1 MiB；这是前轮重设计后的调整值，不等于更早的 19 MiB 门禁。本轮未继续抬高阈值。

首次使用会迁移本机 Token JSON，并保留迁移前备份。回退旧程序时请保留 SQLite 和现有数据，旧程序只能读取其支持的旧口径。删除会话默认保留产物文件；勾选删除文件仅处理已登记且归属明确的图片。

## 下载与校验

- Setup：Windows x64 安装包。
- Portable ZIP：Windows x64 便携包，用户数据仍保存在 %APPDATA%\Grok Build Desktop。
- 随附 SHA256SUMS.txt、CycloneDX SBOM 与第三方许可证。

CLI 单独安装，本次发布不会替用户升级。安装包未签名；请核对 Release 的 SHA-256。正式工作流会对资产生成来源证明，并下载回验后发布为 Latest。
