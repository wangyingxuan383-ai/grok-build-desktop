# 0.14.2 本地检验候选版

- 拖动开始播放拎起过渡，再保持悬空姿势。
- 松手后原地播放收势／站稳动作，然后恢复真实任务姿态。窗口停在松手位置，不自动落底。
- “落到底部”继续播放真正的下落与落地；没有移除这组动作。
- 新拖动、隐藏、关闭会取消旧收势，等待确认与错误优先显示；减少动态效果、仅状态和勿扰时直接恢复状态。

沿用现有动作素材，不新增配置、权限或依赖。手机端不变，不公开上传。Windows 实体鼠标穿透、多屏／混合 DPI 和锁屏体验仍需单独验收。

已通过类型检查、1444 项桌面测试（9 项环境跳过）、生产构建、原有资源门禁和 36 项包内窗口／IPC 检查。窗口检查确认拎起、原地收势及坐标稳定；当前版本页面、隔离任务计划程序、中文／空格路径便携启动、包内容及 Fuses 检查通过。这些检查不替代实体输入体验。
