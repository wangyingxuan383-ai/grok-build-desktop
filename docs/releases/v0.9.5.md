# Grok Build Desktop v0.9.5｜更新恢复修复

- 发布审计补修：smol-toml升级至1.8.0，修复畸形TOML拒绝服务公告，未改变主进程/沙箱边界。

## 简洁版

- 修复升级失败后策略无法再次选择，支持重新预览、重试升级。
- “重新验证”现在验证当前实际CLI；回滚版本来自连续升级前的动态恢复点，不是固定1.0.0。
- 修复非Git目录中的可选检查异常导致升级、回滚及重连被错误阻断。
- 桌面应用更新检查使用应用设置中的代理，改善403/限流提示，失败后可以立即重试。
- 单次CLI下载/安装等待上限为5分钟；超时保留脱敏诊断，不再盲等30分钟。

## 详细版

### 升级与恢复

恢复中的用户可以重新选择策略，仍须预览和确认固定目标；连续失败保存最初回滚点及待恢复会话。已在目标回滚版本时不重复下载，但必须通过核心验证。联网刷新不再阻塞本地操作解锁，迟到检查不会覆盖下一次操作。

核心initialize/new/resume/close/delete仍必须成功；Git、Info、Usage和重命名仅为可选检查。核心失败继续保留恢复清单，不启动被隔离的会话，不自动重发提示词。版本不符显示目标、实际版本和执行路径；识别手动安装CLI不支持自更新的成功退出空操作。

### 网络与超时

GitHub Release检查通过独立Electron网络分区应用当前代理；403/429按响应证据分类，失败不缓存六小时，保留官方发布页入口。不绕过代理或静默安装桌面应用。

5分钟是单次CLI下载/安装预算，文件锁重试共享；必要回滚、ACP验证与会话恢复另有预算，不保证整个事务五分钟结束。超时保留最后8KiB脱敏输出并修复终止事件覆盖超时原因的竞态。

### 实测边界

已实机复现旧更新器在非Git探针失败后回滚仍被隔离的问题；修复版完成1.0.3与官方1.0.24之间的安装、回滚、核心ACP及同一会话恢复。该安装试验使用已校验的官方原文件缓存。真实Electron代理查询GitHub Release成功。

默认公网下载曾在30分钟内未完成；本版限制等待，不宣称已根治代理或下载速度。另一台电脑首次版本不符仍需其日志确认。新分段下载原型另有一次1.0.25实机成功记录，但自动化回归尚未完成，因此不混入此版本。

### 下载

- Setup：常规安装/升级。
- Portable ZIP：解压运行。
- SHA256SUMS、SBOM和第三方许可证随附；正式工作流上传后下载回验再发布。

不会捆绑或自动替换Grok CLI；更新CLI仍由用户在应用中明确确认。
