# Grok Build Desktop v0.8.2｜设置保存热修

本版本修复 v0.8.1 中“只要改设置就保存失败”的阻断问题。建议所有 v0.8.1 用户更新。

## 简洁说明

- 修复设置页保存时因未知字段 `automaticUpdateChecks` 被 IPC 拒绝。
- 设置草稿里的上次自动检查时间可以随完整对象提交，但不会被界面改写。
- 为设置和 Computer Use 配置增加类型与 IPC 白名单对齐检查，降低同类回归。

## 详细说明

设置界面会把当前完整 `AppSettings` 发给主进程。0.8.0 增加了启动/24 小时自动检查开关，却没有把它加入 `settings:update` 白名单，因此改字体、代理或任何其他选项都会失败。

v0.8.2 允许这两个已存在的字段通过运行时校验；`lastAutomaticUpdateCheckAt` 仍只由主进程在实际检查后写入。

## 升级说明

- 可直接覆盖安装 v0.8.1 / v0.8.0，现有会话和设置会保留。
- 安装包尚未签名，Windows 首次运行可能显示 SmartScreen 提示。
- 本轮不改 Grok Build CLI 协议。
