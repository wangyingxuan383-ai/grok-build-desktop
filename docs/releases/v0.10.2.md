# Grok Build Desktop v0.10.2

本版集中修复任务、用量和媒体的状态一致性，并改善常用交互。

## 更新内容

- 更新 DOMPurify 3.4.16 安全补丁。

- 定时任务增加运行筛选、结果查看、重试和历史清理；重复触发去重，运行历史有容量上限，拒绝确认显示部分执行。
- 子智能体工具调用与主会话分别计数；累计 Token 单独记录并合并原生/子会话身份，避免重复计入父回合。
- 账号变更保护正在执行的编程、CLI 生图和同账号定时任务；登录与普通版本白名单解耦，验证失败的 CLI 更新仍需恢复或回滚。
- 图片清理核验来源与内容；缺少旧版证明的现存文件保留。提供原图恢复、固定图片视图和更明确的生成等待、认证、限流及连接提示。
- HTML 右侧预览支持内联交互，保持独立来源、应用 IPC 隔离和离线资源策略；更多代码及配置格式支持只读预览。
- 修复深浅主题对比度、图片预览 Esc/焦点、搜索残留、分段工具标题和历史回放的统计副作用。
- 安装器正常更新保留计划任务；公开文档聚焦产品说明，内部交接及机器信息不进入发布内容。

## 验证与边界

通过相关离线回归、类型检查、源码/打包检查及隔离界面/IPC 验证。发布工作流核验附件 SHA-256 与构建来源。

真实连续编辑、当前 CLI 的 Computer 调用证明及父子隔离、子智能体消息/取消语义和 Windows 到时触发仍需专项实测。直接 Provider 图像用量尚未进入统计；不自行估算缺失总量。HTML 外部资源不加载，Office 仅提供内容提取。终端与网页预览是手动工具。

本版不捆绑或自动升级 Grok CLI，不执行额度重置。安装包尚未签名。历史清理不能召回已下载附件、fork 或第三方缓存。
