# 0.12.2 / Grok Remote 0.4.2 本地检验版

本版取代未公开发布的 0.12.1 / 0.4.1 本地检验版。保留现有导航、配对协议和 CLI 配置含义；检验包尚未公开发布。

- 完整传递 CLI 模型上下文容量；缺少或非法容量保持未知。输入区上下文环在未知时只显示空环，说明放在悬停提示里。
- Memory 旧参数缺失时保留未知判断；能力证据绑定实际 CLI 二进制身份。
- 原生目标与工作流有三个入口：
  - 电脑任务中心：按会话分组，可筛选"进行中 / 需处理 / 全部"。
  - 当前会话右侧"侧边任务 → 任务"。
  - 手机：任务页、会话页状态标签、"会话工具"。
- 控制门禁改为协议基线：运行中的 CLI 报告 1.0.60 或更高版本，声明对应命令，并使用完整原生 ID、实时修订号和原生回执。不再绑定单一二进制哈希。未确认的结果显示为待确认，不自动重发。
- 不再改写用户的 leader 配置。打开会话不再等待目标状态读取。新的实时状态会结束"待确认"。
- 重启后的记录保留最后已知状态，并标注"上次记录"。已结束或恢复的记录可以移除。同一会话的同名任务显示短 ID。
- 后台工作流完成、失败或预算用尽时提醒一次。用户主动结束和历史回放不提醒。
- 在线会话从任务列表正常打开，恢复的记录只读查看历史。
- 未连接的会话在会话信息页显示一行说明，不再弹出 IPC 错误。全局错误提示去掉 Electron IPC 前缀。
- 会话搜索支持多个词、不分顺序（电脑侧栏、Ctrl+K、手机）。输入区下拉框宽度贴合当前选项。右侧窗格字号改用设计变量。
- 仓库脚本和"安装/更新 CLI"窗口在装有 PowerShell 7 时优先使用它，否则回退 Windows PowerShell 5.1。
- 手机：状态色与背景一致，控制结果按电脑回执显示，"运行"计数只统计执行中的项目。

## 已验证

- 实际 Desktop 适配器和隔离回环 Provider，分别使用官方 Windows 1.0.60、1.0.62 二进制，验证：
  - 目标暂停、恢复、清除。
  - 工作流暂停、恢复、停止。
  - 同名工作流隔离、重复操作合并。
  - 启动参数不含 `--no-leader`。

  1.0.62 二进制下载到独立目录，Authenticode 签名有效（X Corp.），没有替换已安装的 CLI。没有调用账号模型。见[1.0.60 记录](../upstream-snapshots/grok-build-1.0.60-review.json)与[1.0.62 记录](../upstream-snapshots/grok-build-1.0.62-review.json)。
- 桌面类型检查与完整回归，手机类型检查与模型、界面、工作流、启动检查，结果见检验说明。

## 保留的边界

工作流真实完成时的提醒只有单元测试覆盖，回环环境无法产生完成事件。Android 输入法、手势、后台恢复和系统安装仍需真机检验。公开发布另行复核。
