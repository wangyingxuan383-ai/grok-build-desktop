# 0.12.1 / Grok Remote 0.4.1 本地检验版

本轮修正现有信息与控制行为，保留当前导航、配对协议和 CLI 配置含义。检验包尚未公开发布。

- 完整传递 CLI 模型上下文容量；缺少或非法容量保持未知。
- 输入区与详情共用当前上下文数据，合并事件触发的查询，丢弃旧会话或配置的响应。
- Memory 旧参数缺失时保留未知判断；能力证据绑定实际 CLI 二进制身份。
- 在现有任务区域管理 Desktop 已接管的 Goal / Workflow；默认折叠显示类型、会话和状态，展开查看阶段、原因及上游预算。
- 通过完整原生 ID、状态修订与操作 ID 控制，等待原生确认；未知结果不自动重发。查看历史不恢复 CLI，控制回执不触发产出提醒。
- Windows 排除依赖测试、示例、源码映射和覆盖率资料；Android 在编译时移除本机诊断路径并延续原签名。

电脑入口为“任务中心 → 队列与后台”，手机入口为“任务 → 运行”。没有原生任务时不显示新增分组。原生任务仍通过原生命令启动，没有新增创建表单。

## 已验证

- Desktop 类型检查及完整回归：1253 项通过、9 项按环境跳过；额外 DOM 回归覆盖原生任务的只读历史导航。
- Android 类型检查、模型与工作流/界面检查：104 项通过，包括新增的构建顺序和文本转义回归。
- 实际 Windows 1.0.60 与 Desktop 适配器通过隔离本地 Provider 验证 Goal 暂停/恢复/清除、Workflow 暂停/恢复/停止及同名任务隔离。见[脱敏行为记录](../upstream-snapshots/grok-build-1.0.60-review.json)。
- Windows 生产分块预算、打包资源、Fuses、界面缩放、页面入口、任务调度器与中文/空格路径便携启动通过。
- APK 包名、版本 0.4.1（13）、原签名、原生模块和深层内容检查通过。双端检查未发现本机路径、凭据字面量、私人状态、签名材料、原始日志或测试夹具文件。
- 实际组件检查覆盖浅色/深色、手机窄屏和放大字体；这些检查不替代 Android 真机行为验收。

## 保留的边界

原生控制只对行为记录中已验证的二进制开放。重启恢复的摘要、其他 CLI 身份和归属不明的执行回合保持只读。本轮不提高最低 CLI 版本，也不自动升级 CLI。

未验证账号模型与计费、真实长会话模型行为和 Android 的输入法、手势、后台恢复、系统安装。历史协议回归超过 4 MiB 不等于真实模型长会话验收。

依赖审计仍报告 Desktop 构建链 9 项中危，手机依赖树 13 项中危、24 项高危。手机六个直接告警包（braces、node-forge、image-size、postcss、sprintf-js、uuid）均未出现在本次 APK 对应的 1400 个 JS 源模块中。构建工具链告警仍需跟进，本轮未升级 Expo / React Native 大版本。公开发布另行复核。
