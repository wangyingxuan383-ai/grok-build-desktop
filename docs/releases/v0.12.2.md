# Grok Build Desktop 0.12.2 / Grok Remote 0.4.2

本次主要接入 Grok Build CLI 的原生目标（`/goal`）与工作流（`/workflow`）管理，修正上下文、模型容量与能力检测，并整理电脑与手机的相关界面。同时提供配套 Windows 安装版、便携版和原签名 Android APK。0.12.1 / 0.4.1 是未公开的检验版本，其改动已全部包含在本版中。

## 原生目标与工作流

- 在已有入口中查看和控制由 `/goal`、`/workflow` 启动的任务：
  - 电脑任务中心的"队列与后台"：按会话分组，可筛选"进行中 / 需处理 / 全部"。
  - 当前会话右侧"侧边任务 → 任务"。
  - 手机：任务页、会话页的状态标签，以及"会话工具"。

  没有任务时不显示新区域，也不增加创建表单或额外轮询。
- 状态用颜色区分：执行中、已暂停、需处理、预算用尽、失败。Token 与 Agent 预算分别显示。同一会话的同名任务带短 ID。
- 暂停、恢复、结束使用完整原生 ID、实时修订号和 CLI 回执；未收到确认时显示"待确认"，不会自动重发。结束目标前会请求确认。
- 控制适用于报告 1.0.60 或更高版本的 CLI，已用官方 Windows 1.0.60 与 1.0.62 验证。保留用户的 leader 配置；打开会话不再等待目标状态读取。
- 电脑重启后保留最后已知状态，标注"上次记录"。已结束或恢复的记录可以移除，只删除本地摘要。查看历史不会重新连接 CLI。
- 后台工作流完成、失败或预算用尽时提醒一次；用户主动结束和历史回放不提醒。

## 修正与改进

- 新建会话与恢复时完整保留 CLI 声明的模型上下文容量，缺失时显示未知，不虚构上限。
- 输入区与右侧详情统一显示当前上下文占用，并与累计用量分开统计。未知时只显示空环，说明放在悬停提示中。
- CLI 不再公布旧的 Memory 参数时，按"未知"处理，不误判为功能删除。能力缓存绑定实际 CLI 文件，更换 CLI 后重新检测。
- 未连接的会话在会话信息页显示简短说明，不再弹出错误；所有错误提示去掉内部通道前缀。
- 会话搜索支持多个词、不分顺序（电脑侧栏、Ctrl+K、手机）。输入区的模型、强度与模式选择宽度贴合当前选项。
- 安装或更新 CLI 时，若已安装 PowerShell 7 则优先使用，否则使用 Windows PowerShell。
- 手机状态色与背景一致；控制结果按电脑回执显示；"运行"计数只统计执行中的项目。
- Windows 安装包不再包含依赖测试、示例、覆盖率资料和源码映射。

## 安装与验证

电脑安装版和 Android APK 可覆盖安装并保留数据；便携版替换解压目录即可升级。建议两端一起更新。已安装 0.4.0 的手机可从"设备 → 手机更新"下载并校验，再由 Android 系统确认安装。

本 Release 包含两端安装包、统一 SHA-256 清单、Windows 依赖清单与许可证，以及 Android 签名、版本和源码记录。

已通过的检查：
- 类型检查、单元与界面回归、原生构建、渲染分块预算。
- 打包后界面检查、便携版启动。
- 隔离环境中的原生控制验证：使用本地回环 Provider，不调用账号模型。

浏览器与模拟检查不代表真机行为；输入法、触摸手势、后台恢复和系统安装确认需在实际手机检验。

APK 使用 arm64-v8a / x86_64 架构。不会自动更换 CLI 或启用模型执行。
