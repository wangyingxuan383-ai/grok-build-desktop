# 0.14.0 Windows 本地检验候选版

本版尚未公开发布。Android 不增加桌宠，现有手机连接和安装不作替换。

- 桌宠默认开启，默认 B 小只形象、192 DIP；可切换 A 原创插画。已明确关闭的设置保持关闭。
- 新增轻跃落地出场和挥手鞠躬退场。暂时隐藏只作用于本次运行，关闭桌宠会持久保存，退出应用沿用原有确认流程。
- 工作、待确认、真实完成、失败和空闲使用现有活动与收件箱数据。浏览和配置变化不触发庆祝；相关会话通过只读历史路径打开。
- 悬停浮条提供提问、截图、任务和菜单。截图与剪贴板均需要明确操作；桌宠不批准权限、不代替原有任务控制。
- 设置内可以选择形象、尺寸、仅状态模式、空闲小动作、减少动态、位置锁定及兼容显示；修改立即保存。
- 支持 PNG/WebP 单图和数据型动画 ZIP 导入；单图在沙箱内检查透明边界并对齐脚底。可调整自定义缩放和脚底位置。
- 生图工坊在既有图像会话准备一项草稿，由用户补充参考图、检查模型并发送。不会后台批量生图或自动重试。
- 包含此前输入法 Escape、迟到附件、手机本地库读取保护及网页弹窗层级修复。

## 仍需系统实测

自动化证据覆盖沙箱窗口/IPC、逻辑隐藏原因、快速开关、事件去重、导入及设置布局。
系统鼠标输入未进入隔离测试窗口，因此不把脚本调用成功写成点击穿透通过。
请在实际 Windows 桌面检查透明空白穿透、拖动、锁屏恢复、全屏收起和混合缩放/拔屏恢复。
这些项目通过前，不把本候选版标记为正式发布。

## 自定义动画包

ZIP 根目录放置 `skin.json` 和被引用的 PNG/WebP 图集，不含子目录或脚本。
清单字段包括 `id`、`name`、`author`、`license`、`clips`；每个动作包含文件名、图集尺寸、参考人物高度、循环标记及帧矩形/脚底锚点/毫秒时长。
待机动作必须存在，其余动作可以省略。缺失出入场使用短淡入淡出，单图保留状态标记。
单个导入文件最多 24 MiB；ZIP 最多 128 项、解压后总计 32 MiB、单项 12 MiB，图像最长边不超过 4096 像素。原作者和许可信息保留在形象清单中。
