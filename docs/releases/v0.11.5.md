# Grok Build Desktop v0.11.5 / Grok Remote v0.3.6

本版首次同时提供 Windows 桌面和签名 Android 客户端，包含此前桌面与手机体验改进及本次审核修复。

## 下载与安装

- Windows Setup：安装或覆盖更新，保留会话、配对和设置。
- Windows Portable：解压运行；便携版升级通过替换解压目录完成。
- `Grok-Remote-v0.3.6.apk`：Android API 24+，支持 ARM64 与 x86-64；沿用既有应用包名和签名，可覆盖安装保留配对与草稿。
- `SHA256SUMS.txt`：全部附件校验值；另附桌面 SBOM、许可证及 Android 构建记录。

桌面“首次设置 → 手机版”和“设置 → 手机连接”均提供 APK 下载二维码和链接。安装后在手机扫描电脑的配对二维码，并在电脑明确允许访问。

## 改进与修复

- 手机作品页保留现有网格、卡片和收藏，修复“网格／卡片”切换被说明文字挤出屏幕；卡片图片也进入全屏相册。
- 全屏看图支持左右翻页、缩放、收藏和保存。取消收藏保持当前看图位置，旋转保留页码；原图缓存纳入清理额度，并保留文件名和 MIME 信息。
- 手机新建会话采用折叠步骤、项目搜索与最近项目优先；会话支持滑动收藏、归档及带确认的删除，消息和作品支持长按操作。
- 只有真实回答回合结束才发送完成提醒；模型、强度和模式修改不再产生虚假完成、未读和推送。通知可返回会话，图像会话 CLI 目录从编程项目目录排除。
- 改进 Android 键盘避让、连接错误恢复、断线提交保护、跨电脑数据和迟到请求处理。
- 桌面采用正式托盘图标与手机在线标记，提供设置引导、鼠标选中文字引用和整条引用。
- 桌面安装版可在应用内下载安装包，校验后明确点击安装。修复重复点击下载竞争、磁盘写入错误和安装进程启动失败；CLI、代码或图像任务运行时阻止关闭更新。
- 手机 0.3.6 新增独立在线升级：无须电脑在线即可检查公开版本、显示下载进度、取消下载；校验 SHA-256、大小、包名、版本及当前签名后调用系统安装器。首次使用可能需要允许应用安装权限；不会静默安装。
- 发布流程要求同时存在签名 APK 和构建记录，独立回下载校验后才发布，防止漏传手机客户端。

## 验证与边界

桌面与手机类型检查、离线回归、原生 Android 构建、签名/包身份/隐私检查和隔离界面走查用于本次验收。发布流程重建 Windows 附件并核验其来源证明；Android APK 使用维护者私有签名本地构建，构建记录明确标注这一来源，不宣称 GitHub Actions 编译了签名 APK。

当前手机系统输入法、双指手势、通知权限以及系统安装确认仍需具体设备检验。模型运行、真实图像编辑和后台推送受 CLI、账号、系统与网络环境影响；离线测试不替代这些验收。本版未调用付费模型，不自动升级 CLI。
