# Grok Build Desktop 0.10.3

This update completes the media, notifications and task-management follow-up.

- Windows Provider credential reads use structured stdin; CLI media requests honor Desktop proxy settings and an explicit dispatch model.
- Image conversations restore complete drafts and request settings. Waits distinguish dispatch from generation and can be extended without resubmission. Gallery selection supports comparing two images.
- Completion, failure and confirmation notification preferences support precise activation targets and inbox result navigation.
- Task-center reads degrade independently, preserve editing state and expose existing instructions, quick schedules and run results.
- Child-session views show evidence level and recent work. Follow-up is prepared in the parent draft; cancellation follows declared native support.
- Local HTML previews can load adjacent assets. Workspace development scripts can be started, stopped and previewed; screenshots and region feedback are added to a conversation draft.
- Usage refreshes after tasks and records explicit Provider image reports. Missing totals remain unknown, and child reports stay separate from parent totals.
- Optional GitHub CLI integration displays a branch PR and CI results; monitoring is limited to the running application.

Authenticated CLI image editing, native child cancellation and model Computer behavior remain separate live acceptance items. This update does not upgrade the Grok CLI or silently switch image billing routes.
