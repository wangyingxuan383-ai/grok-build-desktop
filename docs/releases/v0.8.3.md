# Grok Build Desktop v0.8.3｜权限、模型目录与额度

## 简洁说明

- 自动批准和 Plan 不再询问工具权限，也不再禁止编辑。
- Agent 模式仍会询问。
- 设置里的默认模型/思考档位与会话选择器共用同一套模型目录。
- 月额度能识别官方接口的新字段形态。

## 模式

| 模式 | 工具权限 | 编辑 |
|------|----------|------|
| Agent | 询问 | 允许 |
| Plan | 自动批准 | 允许 |
| 自动批准 | 自动批准 | 允许 |

Plan 结束时的「批准并执行」卡片仍保留。

## CLI

公开 Changelog 仍是 1.0.0。开源 crate 为 1.0.1。未证实稳定频道 1.0.3，本版不擅自升级本机 CLI。
