# Grok Build Desktop v0.10.4

本版包含自 0.10.2 以来的媒体、任务和桌面体验改进，以及启动更新检查与图库优化。

## 更新内容

- 默认在每次启动后检查桌面应用和 Grok CLI 的稳定版本；持续打开时每天检查一次。两种模式都显示可关闭的更新红点，只检查，不自动安装。
- 图库默认只展示图片，保留“全部”“失败”筛选和清理；支持两图比较、完整生成参数复用与图像草稿恢复。
- 修复 Windows Provider 环境变量读取，CLI 生图使用桌面代理和明确模型；区分临时认证、缺失凭据与连接故障，并允许延长同一次生成的等待。
- 完成、失败及待确认通知提供独立设置，通知和收件箱可返回对应会话、图像或任务记录。
- 任务中心支持逐项加载、编辑保护、读取既有指令、快捷时间预设及结果查看；每周星期选择保持紧凑。
- 子智能体显示近期动作、父子关系与历史证据；跟进先进入父会话草稿，取消按 CLI 的实际声明开放。
- 右侧 HTML 预览支持同目录 CSS、JS、图片和 JSON；增加手动开发服务器预览、网页截图及区域反馈。
- 用量在任务结束后刷新，记录 Provider 明确返回的图像用量，修正累计子智能体图表；缺失总量不自行估算。
- 增加基于 GitHub CLI 的 PR/CI 状态与可选完成监听，改善终端主题和进程结束提示，修复 Windows 工作区名称显示。
- 更新项目介绍和六张隔离演示截图，清楚列出已实现功能与后续体验改进方向。

## 下载

- Setup：当前用户安装版，正常更新保留应用数据。
- Portable：解压后运行，用户数据仍位于 Windows 应用数据目录。
- `SHA256SUMS.txt`：附件校验值；同时提供 SBOM 和第三方许可证报告。

## 验证与边界

发布沿用源码检查、离线回归及打包验收；工作流从正式标签构建附件，再回下载核验 SHA-256 和构建来源。此前隔离界面验收覆盖图像草稿、模式切换、更新提示、图库筛选、通知目标、HTML 本地资源和截图反馈。

真实 CLI 连续图像编辑、Computer 调用证明与父子隔离、部分原生子智能体操作仍需对应账号和模型的实际验收。浏览器和终端当前是手动工具；系统通知受 Windows 设置影响，PR/CI 需要已安装并登录的 GitHub CLI。

不捆绑或自动升级 Grok CLI，不静默切换收费 Provider，不执行额度重置。安装包尚未进行代码签名。
