# Grok Build Desktop v0.11.6 / Grok Remote v0.3.6

本次修复应用内在线升级的代理兼容问题，同时提供 Windows 安装版、便携版和同签名 Android APK。

- 标准代理 URL 末尾带 `/` 时，Chromium 会拒绝将其当作代理规则，造成更新检查、APK 二维码和下载失败。现在网络入口统一使用代理的协议、主机和端口，保留直连选择和既有多协议规则。
- 修复同时覆盖继承应用代理的 Provider、额度查询和可选推送网络；没有切换账号或升级 CLI。
- 手机 APK 保持 0.3.6、versionCode 11 和原签名。附件中的 APK 与 0.11.5 Release 完全相同，Android 构建记录仍指向其原始来源提交。

## 下载与升级

Windows Setup 覆盖安装保留数据；便携版通过替换解压目录升级。Android APK 覆盖安装保留配对和草稿。此前手机 0.3.5 或更早版本需要先安装 0.3.6，以启用独立在线检查、下载校验和系统安装入口。

桌面首次设置及手机连接页面提供 APK 二维码和下载链接。手机网格／卡片、全屏相册、折叠新建、长按／滑动和可靠提醒等完整改进见 [0.11.5 发布说明](https://github.com/wangyingxuan383-ai/grok-build-desktop/releases/tag/v0.11.5)。

附带统一 `SHA256SUMS.txt`、SBOM、许可证和 Android 构建记录。Windows 附件由公开标签构建并验证来源；APK 维持维护者私有签名的本地构建来源。

系统输入法、原生手势和安装确认仍需具体手机检验。没有自动更换已有安装，也没有调用付费模型。
