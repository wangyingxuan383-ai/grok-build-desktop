### 2026-09-25 文件、审查和产物目标接入

- `file` 目标使用现有编辑缓冲身份，激活后恢复对应文件；非焦点窗格显示只读预览并限制为 160 KiB。
- `review` 目标按路径与暂存状态恢复 Git 选择；有已载入差异时显示只读片段，限制为 160 KiB。
- 原生 Grok、Codex 与 Claude 会话进入不同布局身份，切换会调用对应现有会话入口；未加载的外部会话在预览窗格只显示标题。
- 编辑器标签按工作区显示；跨工作区切换不把旧文件误显示到新工作区，回到原窗格仍保留各自编辑缓冲。
- Git 仓库刷新保留仍存在的文件/暂存状态选择；文件已消失或切换仓库时清除过期审查目标。
- 文件树新增“预览”入口，带文件路径进入产物页面并自动读取；另存原文件改为主进程受信路径复制，不先将大文件读入内存。
- 会话投影限制最近 80 条用户/助手消息，每条显示最多 12,000 字符，降低多窗格下的排版开销。
- 将 App 的 Zustand 订阅移动到所有早退分支之前。真实 Electron 检查捕捉到启动时 hook 顺序错误，修复后重新通过页面探针。
