# UI 深度学习与规划（舒适、美感）

日期：2026-08-19
范围：只规划视觉与阅读体验。2026-08-19 落地的阅读层已按用户验收撤回，产品皮肤回到 0.9.0。
边界：官方 Grok CLI 的 Windows 桌面壳。不做多 Agent、不做手机遥控。不抄 FSL 源码。

用户纠正两次：

1. 要的是 **好看、好读、好点**，不是协议/状态/队列。
2. 舒适是 **非常多的小细节**，不是 U0–U4 几个阶段。

**实施清单以 `docs/UI_DETAIL_CATALOG.md` 的 D001–D228 为准。** 本文只记气质和边界。不要用下面的段落代替那份清单。

---

## 1. 现在长什么样

视觉人格是 **被压扁的工程工具**：能用，但不想多看一眼。

不是缺一个 Token 阶段。是同一窗口里同时存在：

- 三层 CSS（`base` / `shell` / `workbenches`）对同一控件各写一套
- Markdown 正文几乎没有标题/段/列表/行内代码样式
- 流式 `<pre>` 和定稿 Markdown 切换时跳布局
- SVG 图标和 `›_ × ✎ ▤ ◉` 混用
- 选中语言四种（左条 / 顶条 / 底条 / 无条）
- 主按钮三种（Composer 白圆、设置蓝填、Git 无边满宽）
- 复制/⋯/评论默认 opacity 0 或 visibility hidden
- 只在约 5 处有 focus-visible；滚动条 10px；pulse 四处一起闪

皮肤还是调试器。信息架构已经像桌面产品。

---

## 2. 目标气质

**夜里也能读完一篇长回答的书桌，不是机房。**

- 深色：略暖的墨。强调色降低饱和。
- 浅色：接近纸，侧栏比画布只深半级。
- 中文：雅黑。caption ≥ 12px。标题略收字距。
- 过程安静、答案清楚。执行过程是细行，最终回答是唯一亮块。
- 不要霓虹、扫描线、每张卡投影、pulse 当默认呼吸。

学谁的样子（只学观感）：Grok-UI Minimal Calm 的 160ms / 不位移 / 关发光；phuryn 截图的阅读列；Codeg 的全局圆角 token。不学 Event Horizon HUD、不抄 FSL、不学 OpenCode 电影黑。

---

## 3. 落地顺序（按表面把 D 项做完，不是按阶段口号）

1. 停战：同一选择器只留一处可见规则。
2. 对话阅读（含 Markdown 排版、流式/定稿、复制常驻、栏宽公式）。
3. Composer。
4. 侧栏 + 顶栏。
5. 决策卡 + 弹层家族。
6. 浅色、密度、滚动条、焦点、reduced-motion —— 乘在已改面上复验。

每一面过深色 / 浅色 / 紧凑/宽松 / 125% 字号 / 窄窗，以及空、加载、错误、hover、键盘。
