## 精确复现“实际版本不是固定目标”

使用 v0.9.4 原版更新器源码和明确的隔离假运行时，构造 previousVersion=1.0.0、targetVersion=1.0.24、retained=true、当前版本1.0.0。

1. 点击旧版“重新验证1.0.24”，preview 返回 from=1.0.0、target=1.0.24。
2. verify 不重新安装目标，却比较当前与历史目标，因此产生“CLI 实际版本不是固定目标”。
3. 随后回滚1.0.0，注入非 Git 探针异常，得到完整文字链：`CLI 目标更新失败：CLI 实际版本不是固定目标；回滚也未通过：hub error: not a git repository`。

所以截图这句话**可能是回滚后再次验证的二次错误**，不必然说明下载了错误文件。这是旧源码故障模拟证据，不是另一台电脑操作顺序的证明，不能认定其首次升级失败原因已确定。
