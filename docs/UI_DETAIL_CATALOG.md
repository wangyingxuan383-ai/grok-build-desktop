## 怎么用这份清单

每一条都是「眼睛或手会感觉到」的差异。格式：

`D编号` · 控件 · 当前 · 为什么不舒服 · 目标

状态默认要过这几格（没写等于缺失）：静息 / hover / active / focus-visible / disabled / selected / empty / loading / error。现在大量控件只做了静息 + 偶尔 hover。

规范目标（所有 D 项共用，不要每个组件再发明一套）：

| 角色 | 目标 |
|---|---|
| 字号 | caption 12 / ui 13 / body 15 / title 16–18 / display 22–28 / code 12–13。中文 caption 不得 < 12px |
| 字重 | 400 正文、500 UI、600 标题。删 520/550/560/590/650/750 |
| 行高 | UI 1.35、正文 1.7、代码 1.55。对话里只许一种正文行高 |
| 圆角 | s=6 芯片/小钮、m=10 卡/菜单、l=16 Composer 与决策卡。圆钮只许发送/停止 |
| 间距 | 4 的倍数。行内 4/8，卡内 12/16，列 24 |
| 选中 | 全产品一种：浅 tint。不要有的左边条、有的顶条、有的去条 |
| 主操作 | 一种实心：浅色字填深底（现 Composer 发送）。设置/权限/空状态跟着它 |
| hover | 背景约 8%，**160ms ease-out**，不位移 |
| 隐身控件 | 复制/评论/⋯ 默认 opacity .45，不要 0 |
| pulse | 只给「正在生成正文」一处 |
| disabled | opacity .4 一档 |
| 焦点 | 全局 2px focus-visible 环，禁止 `outline: 0` 且不补环 |
| 图标 | 只用 `UiIcon`。禁止 ▤ ▰ ›_ × ✎ ≡ ◆ ◉ ✦ 当主图标 |
| 弹层 | 一种圆角 m、一种阴影、项高 32、字 ui 13 |
| 栏宽 | 对话/Composer/队列/hydration/跟进/批注草稿共用同一公式 |

## 0. 先把「会乘到每一块」的系统写清

这些不是五个阶段，是每一像素都在吃的公共债。

### 0.1 三层样式互相覆盖

`base.css` 先给一套（侧栏 264、顶栏 58、发送 38×36 方角 accent、气泡 chip-bg、过程有边框）。
`shell.css` 再压一套（侧栏 274、顶栏 52、发送 32 圆、气泡 panel-3、过程去边）。
`workbenches.css` 再写 `--topbar-height: 48`、`--content-width: 760`。

密度 token（compact/comfortable）在 base 和 shell **各写一遍且数字不同**。shell 里大量写死 `height: 48px`、`min-height: 34px`，密度切换几乎不作用在品牌行、搜索、分组标题上。

### 0.2 Markdown 几乎没有排版

`.assistant-body` 只定了颜色和 `h1–h3` 变 `text-strong`。没有：

- h1/h2/h3 字号、字重、段前段后
- p 段距（现在吃浏览器默认约 1em，和行高 1.62 打架）
- ul/ol 缩进、li 间距、嵌套列表
- blockquote 左条
- hr
- 行内 `code` 底和垫
- img 圆角/最大宽
- GFM 任务列表、脚注
- KaTeX 与正文基线

长回答看起来「能读」，但标题不像标题、列表像浏览器默认、段与段忽大忽小。这是久坐最累的一层，上一轮几乎没写。

### 0.3 流式和定稿是两种排版

生成中：`<pre class="streaming-answer">`，行高 1.7、等宽关掉、无 Markdown。
生成完：切到 `LazyMarkdownView`，行高又变 1.62/1.72，列表/标题突然出现。
同一段文字在结束瞬间会跳布局。没有「末尾静点」或稳定占位。

### 0.4 图标两套语言

`UiIcon` 是 24 视口、stroke 1.8 的 SVG，调用尺寸有 11 / 12 / 13 / 14 / 15 / 16。
同一屏还混着：`›_`（Consolas）、`×`、`✎`、`↑↓`、`≡`、`◆`、`▤`、`▰`、`▣`、`◉`、`✦`、`G` 方块字标、`C`/`A` 字母标、分组标题用字符串 `›`/`⌄`。
光学重量完全对不齐。减号折叠过程、加号添加附件、发送纸飞机，三者几何无关。

### 0.5 焦点、滚动条、动效几乎缺席

- `textarea`、`.search input`、模型 select 全部 `outline: 0`，多数不补 focus-visible。
- `:focus-visible` 全仓库大约 5 处。
- 无 `prefers-reduced-motion`。
- 唯一 `@keyframes` 是 `pulse`（会话点、顶栏点、思考占位、Computer 点四处一起闪）。
- 全局滚动条 10px 宽。264px 侧栏里标题被吃掉一截。
- hover 几乎只有换背景，无 160ms。

### 0.6 字号随 `fontScale` 失效

设置「文字大小」改 `html { font-size }`。但大量 UI 用 **11px / 12px** 绝对像素（操作通知、队列锁、Mermaid 工具条、turn-metrics、session-tool、open-location 反馈）。滑条拉到 130%，对话正文变大，这些辅助字不动，层级更乱。

### 0.7 硬编码色

`#8bb9d3` `#d69b72` `#8f7bd8` `#4fc17d` `#f06a6a` `#e2b85b` `#d9a441` `#0005` `#0008` `#0009` `#000a` `#000c` `#0d2230f2` `#159eff55` `#4cc4ff` `#343940`（Token 环剩余弧）`#fff`（发送 hover）。浅色主题换 token 换不掉它们。

### 0.8 原生控件和产品弹层混用

顶栏重命名走 `window.prompt`。侧栏重命名走 `askText` 对话框。删除走确认框。三种「问用户」的皮肤。

## 12. 别人在同一粒度上做什么（只记手感）

**Minimal Calm（Grok-UI，只学观感）**

- 纸色、鼠尾草绿、线 `rgba(32,35,31,.14)`。
- hover **不位移**；过渡 **160ms ease-out**；reduced-motion 直接 `animation: none`。
- 选中 inset 2px 只用一次。
- 弹层一种影。
- 关雷达/扫描线。

**对话壳（phuryn 截图语言）**

- 中间是文章；过程是细行不是卡片墙。
- 芯片小，圆角跟输入走。
- 复制/打开低对比常驻，不 `opacity: 0`。

**Codeg**

- 圆角全局一个 token。主题换 token，不写 200 个选择器。
