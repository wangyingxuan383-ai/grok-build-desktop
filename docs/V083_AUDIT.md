## 已修并有测试

1. **自动批准仍弹权限**  
   Resume 把 CLI 的 `default` 当成 Agent，丢掉 Desktop Auto。现已保留 Auto，并且 Auto/Plan 对 `allow`/`allow_once`/`allow_always` 一律代点允许。
2. **Plan 询问 / 禁止编辑**  
   旧 Plan 门自动拒绝写入和修改性命令。现已关闭该门；Plan 只保留结束时的计划确认卡。
3. **设置默认模型列表空、档位写死**  
   设置改为读 ACP 模型目录和该模型声明的思考档位。打开过会话后，目录会缓存。
4. **月额度接口变形**  
   解析兼容百分比、嵌套 subscription/limits 和新字段名。
