### Token 迁移及回退操作

新版首次使用统计时在原 JSON 锁内备份并事务导入 SQLite；新 GUI 和定时 Worker 均写 SQLite，原 JSON 不再更新。退出全部 Grok GUI/Worker 后，备份整个应用数据目录，尤其 token-activity.sqlite、可能存在的 -wal/-shm、token-activity.json 和 .pre-sqlite-backup，再切换二进制。

回退旧版可以继续使用其余旧功能，但旧版只认识迁移前 JSON，不会显示迁移后的新用量。不得用旧 JSON 覆盖 SQLite 或删除迁移标记来“修复”。旧版回退期间新增 JSON 用量尚无自动合并工具；重新使用新版时保留两个来源，不能声称已自动补齐。自动任务需与 GUI 一并切换版本，禁止混用旧 Worker 和新版 GUI。该边界需在实际桌面替换时再次说明。
